# Descrição do sistema

## Proposta

Uma ferramenta web de programação em blocos. O usuário arrasta e encaixa blocos para controlar um robô e o sistema gera o código equivalente em Portugol e em C.

## Objetivo geral

Permitir que uma pessoa monte programas com blocos e veja o código gerado em Portugol e em C.

## Objetivos específicos

- Oferecer blocos de movimento (frente, trás, direita, esquerda), repetir e condicional Se
- Gerar o código em Portugol
- Gerar o código em C
- Mostrar o robô andando na tela
- Permitir cadastro de usuários e login com a conta Google

## Usuários do sistema

A definir com o professor na entrevista de requisitos.

## Metodologia

Scrum com sprints de duas semanas, tarefas no Jira e reunião com o professor a cada duas semanas.
