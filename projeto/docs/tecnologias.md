# Tecnologias

| Uso | Tecnologia |
|---|---|
| Interface | React com TypeScript |
| Editor de blocos | Blockly, com blocos próprios e gerador de Portugol próprio |
| Simulação | SVG |
| Servidor | Node.js com Express |
| Banco de dados | PostgreSQL |
| Login | Google, com OAuth 2.0 |
| Testes unitários e de componentes | Vitest e React Testing Library |
| Testes de ponta a ponta | Playwright |
| Código | Repositório público no GitHub, com issues ligadas aos commits |
| Tarefas | Quadro Kanban no Jira |
| Ambiente | Docker |
| Automação | GitHub Actions |

## Fora do escopo da primeira versão

- Geração de código em C
- Conexão com Arduino ou robô físico
- Aplicativo móvel
- Login por senha ou por outro provedor
