# RF01 Cadastrar usuário

## Descrição

O usuário cria uma conta no sistema informando seus dados.

## Critérios de aceite

- O usuário consegue criar uma conta com nome, e-mail e senha
- Não é possível criar duas contas com o mesmo e-mail
- O sistema avisa quando algum dado está inválido

## Prioridade

Alta

## Depende de

Nenhum
