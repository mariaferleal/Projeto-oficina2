# RF09 Listar e reabrir programas salvos

## Descrição

O usuário vê a lista dos programas que salvou e abre qualquer um deles para continuar.

## Critérios de aceite

- A lista mostra apenas os programas do próprio usuário (RN06)
- Um programa reaberto volta exatamente como foi salvo
- Ninguém acessa nem altera programas de outra conta

## Prioridade

Essencial
