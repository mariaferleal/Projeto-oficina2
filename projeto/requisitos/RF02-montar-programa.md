# RF02 Criar, montar, editar e limpar um programa

## Descrição

O usuário monta o programa com blocos, pode alterar a ordem, remover blocos e limpar a área de trabalho.

## Critérios de aceite

- Os blocos podem ser arrastados e encaixados
- Os blocos podem ser reorganizados e removidos
- Existe uma ação para limpar o programa
