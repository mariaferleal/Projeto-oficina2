# RF05 Bloco Se com condição de borda

## Descrição

Bloco cuja condição verifica se o robô está na borda da área de execução. Os comandos de dentro rodam quando a condição é verdadeira.

## Critérios de aceite

- A condição é verdadeira quando o robô está na borda (RN05)
- Quando é falsa, os comandos de dentro não rodam
- Não existe bloco Senão na primeira versão

## Prioridade

Essencial

## Depende de

RF02 e RF03
