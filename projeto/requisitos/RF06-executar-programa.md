# RF06 Executar o programa com o robô virtual

## Descrição

O sistema executa o programa na ordem dos blocos e mostra cada comando no robô, passo a passo. Se um movimento chegar à borda, o robô continua dentro da área.

## Critérios de aceite

- Os comandos rodam na ordem em que aparecem (RN02)
- O robô é animado passo a passo
- O robô nunca sai da área de execução
- A execução é toda virtual, sem Arduino nem robô físico (RN07)

## Prioridade

Essencial

## Depende de

RF03, RF04 e RF05
