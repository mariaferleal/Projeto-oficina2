# RF10 Avisar quando o programa não puder ser executado

## Descrição

O sistema informa o usuário quando o programa está incompleto ou inconsistente e por isso não pode ser executado nem traduzido.

## Critérios de aceite

- O aviso usa linguagem simples
- Vale para programas incompletos e para valores fora dos limites
- O usuário entende o que precisa corrigir

## Prioridade

Importante

## Depende de

RF06 e RF07
