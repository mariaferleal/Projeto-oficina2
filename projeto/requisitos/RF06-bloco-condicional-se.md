# RF06 Bloco condicional Se

## Descrição

Bloco que executa os blocos de dentro dele apenas quando uma condição for verdadeira.

## Critérios de aceite

- O usuário escolhe a condição do bloco
- Blocos podem ser colocados dentro do Se
- O código gerado traz a condição correta
