# RF04 Blocos de movimento

## Descrição

Blocos para mover o robô para frente, para trás, para a direita e para a esquerda.

## Critérios de aceite

- Existe um bloco para cada um dos quatro movimentos
- Cada bloco pode ser usado na área de trabalho
- Cada bloco gera o comando correto no código
