# RF07 Gerar e exibir o código em Portugol

## Descrição

O sistema mostra o pseudocódigo equivalente em Portugol e o atualiza sempre que o programa em blocos muda.

## Critérios de aceite

- O Portugol aparece na tela sem o usuário pedir
- O código muda quando os blocos mudam
- Cada bloco tem uma tradução equivalente (RN03)
- O código gerado e a simulação seguem a mesma interpretação (RNF03)

## Prioridade

Essencial

## Depende de

RF03, RF04 e RF05
