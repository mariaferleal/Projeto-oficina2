# RF03 Blocos de movimento

## Descrição

Blocos que movem o robô uma unidade visual para frente, para trás, para a direita e para a esquerda, sem mudar a orientação dele.

## Critérios de aceite

- Existe um bloco para cada um dos quatro movimentos
- Cada bloco move o robô exatamente uma unidade visual
- O robô não gira

Essencial
