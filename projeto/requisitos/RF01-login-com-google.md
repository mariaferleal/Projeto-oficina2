# RF01 Autenticar somente com conta Google

## Descrição

O usuário entra no sistema usando apenas a conta Google. No primeiro acesso válido, o sistema cria o cadastro mínimo necessário.

## Critérios de aceite

- O login com Google funciona
- Não existe cadastro por senha nem outro provedor (RN01)
- No primeiro acesso, o cadastro é criado sozinho
- O sistema guarda só o necessário, como o identificador da conta Google

## Prioridade

Essencial

## Depende de

Nenhum
