# RF03 Blocos de movimento

## Descrição

Disponibilizar blocos para deslocar o robô uma unidade visual para frente, para trás, para a direita e para a esquerda, sem alterar sua orientação.

## Critérios de aceite

- Existe um bloco para cada uma das quatro direções.
- Cada bloco desloca o robô exatamente uma unidade na direção indicada.
- O robô não gira nem muda sua orientação.
