# RF05 Bloco Se (condição de borda)

## Descrição

Disponibilizar um bloco Se cuja condição verifica se o robô está na borda da área de execução; executar os comandos internos quando a condição for verdadeira.

## Critérios de aceite

- Quando o robô está em uma borda, os comandos internos são executados.
- Quando o robô não está em uma borda, os comandos internos são ignorados.
- Não existe bloco Senão na primeira versão.
