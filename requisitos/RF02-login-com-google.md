# RF02 Entrar com conta Google

## Descrição

O usuário entra no sistema usando a conta Google.

## Critérios de aceite

- O usuário consegue entrar com a conta Google
- Se for o primeiro acesso, a conta é criada automaticamente
- Depois de entrar, o usuário é levado para a área de blocos
