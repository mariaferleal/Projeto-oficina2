# RF07 Gerar código em Portugol

## Descrição

O sistema transforma os blocos em código Portugol.

## Critérios de aceite

- O código em Portugol é mostrado para o usuário
- O código muda quando os blocos mudam
- O código traz todos os blocos usados, na mesma ordem

## Prioridade

Alta

## Depende de

RF04, RF05 e RF06
