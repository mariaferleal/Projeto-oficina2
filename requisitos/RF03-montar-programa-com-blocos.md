# RF03 Montar programa com blocos

## Descrição

O usuário arrasta e encaixa blocos em uma área de trabalho para montar o programa.

## Critérios de aceite

- O usuário consegue arrastar um bloco para a área de trabalho
- Os blocos se encaixam uns nos outros
- O usuário consegue remover um bloco
- O usuário consegue limpar a área de trabalho

Alta
