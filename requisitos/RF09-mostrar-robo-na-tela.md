# RF09 Mostrar o robô andando na tela

## Descrição

O sistema mostra um robô se movendo na tela seguindo os blocos montados. Esse ponto foi comentado na reunião com o professor e precisa ser confirmado.

## Critérios de aceite

- O robô aparece na tela
- Ao executar, o robô se move conforme os blocos
- O usuário consegue voltar o robô para a posição inicial
